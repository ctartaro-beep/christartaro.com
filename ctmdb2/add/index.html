    Connection to GitHub · Not connected

    "Add to memoir" saves the album straight to the site. It needs a GitHub access token, which is stored only in this browser. You only do this once per device.

    1. Open GitHub → New fine-grained token.
    2. Repository access: Only select repositories → ctartaro-beep/christartaro.com.
    3. Permissions → Repository → Contents: Read and write. Nothing else.
    4. Generate it, then paste it here.
